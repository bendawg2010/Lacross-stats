🔗 Transfer Data to Another Device

Your data is stored locally on this device. To move it, choose a method below.

⚠️ The link only works if the other device also has the CGLacrossStats HTML file. The link carries your stats data — the other device still needs the app file to open it.
Step 1 — Send the HTML file to the other device
AirDrop, email, or copy CGLacrossStats.html to the other device first.
Step 2 — Transfer your stats (choose one)
Option A — Backup file (easiest):
Use Export Backup to save a .laxstats file → send it → open the HTML on the other device → Import Backup.
Option B — Data link:
Copy the link below, open it in a browser on the other device after you've opened the HTML file there.
Generating link…

The link encodes all your match data. It starts with file:/// — that's your local path. On the other device, open their copy of the HTML first, then paste the link.

Install & Setup Guide

How to install CGLacross Stats on your device so it works like a real app — offline included.

Mac macOS · Chrome / Safari

  1. 1
    Download the full project folder from GitHub (green Code → Download ZIP button) and unzip it anywhere — your Desktop works fine.
  2. 2
    Open Google Chrome (recommended) and drag CGLacrossStats.html into the Chrome window, or press ⌘O and select the file.
  3. 3
    In Chrome, click the address bar menu (⋮ or the screen icon on the right side of the address bar) → "Save and share" → "Create shortcut…" → check Open as window → Create. This adds a standalone LaxStats icon to your Applications folder and Dock — it opens without browser chrome.
  4. 4
    All data is saved automatically in your browser's storage. To back up, use Export CSV in the app sidebar.

Want a full native .app? With Node.js installed, open Terminal in the project folder and run npm install then npm run build:mac. A .dmg installer appears in dist/.

HP Chromebook Chrome OS · Chrome

  1. 1
    Download the project ZIP from GitHub. In the Files app (bottom shelf), find it in Downloads and extract it (tap once → Extract all).
  2. 2
    Open the extracted folder in Files, then double-click CGLacrossStats.html. Chrome opens the app automatically.
  3. 3
    To add it to your Launcher (like an installed app): in Chrome, click the ⋮ menu → More tools → Create shortcut… → check Open as window → Create. You'll see "LaxStats" in your Chromebook Launcher just like any Android app. Tap it to open full-screen.
  4. 4
    The app works completely offline after first use — no internet needed at the game.
  5. 5
    To share stats: tap Export CSV in the sidebar. The file saves to Downloads — open it in Google Sheets directly from Files.

Tip: Keep the HTML file in Google Drive → My Drive so you can access it from any Chromebook or phone without re-downloading.
